# Insel-Test

Spielbarer Test für ein neues Lernspiel: Man läuft über eine Insel, löst an Palmen und Felsen echte Aufgaben, bekommt dafür Holz und Stein und setzt damit frei Blöcke und Wege.

Die Fragen stammen aus dem Lernpaket „Irregular verbs – be bis hold“ und stehen direkt in `index.html`.

Der Test speichert nichts und soll nur zeigen, wie sich Laufen, Aufgaben und Bauen auf dem iPad anfühlen.
